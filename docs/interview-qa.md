## A. 业务与动机（非技术面最爱问）

**Q1 为什么做这个项目？**
参考：结合专业（技术经济及管理）——可研/投资决策是我的课程核心；市场痛点：非财务背景的人不会建财务模型，通用 AI 只会编数字。→ 对应 PRD §1。

**Q2 目标用户是谁？解决什么问题？**
参考：中小项目决策者/学生创业者/投资入门者；"算得对 + 讲得清 + 有来源 + 省时间"。→ PRD §2-3。

**Q3 和通用 ChatGPT / Excel 模板 / 咨询公司比，差异是什么？**
参考：ChatGPT 数字靠编；Excel 只有表没报告；咨询贵且黑箱。我们=引擎真算 + AI 成文 + 引用溯源 + 假设可改可重算。→ PRD §8 竞品表。

**Q4 为什么示例是奶茶店？**
参考：投资小、模型直观、面试官都能听懂；且参数可现场改，最能演示"真算"。

**Q5 这个项目是纯个人做的吗？怎么分工？**
参考（诚实版）：产品定义/业务口径/验收由我负责；代码用 AI 辅助开发。
补充：AI 时代评估一个人能否用工具交付结果，我做了完整 PRD、架构文档、单元测试（22 项），你能看到我理解每一层。

## B. 财务与口径（业务+技术交叉，最容易被追问）

**Q6 NPV 和 IRR 是什么？判定规则？**
参考：NPV=现金流折现求和，≥0 可行；IRR=使 NPV=0 的折现率，> 基准折现率可行。→ indicators.py 注释 + app 内"指标解释"。

**Q7 你的现金流口径有什么简化？（主动交代）**
参考：全投资（融资前）口径；直线折旧；亏损年不纳税不结转；收入固定增速；盈亏平衡含折旧；期末回收流动资金+残值。每个简化都是"可讨论的设计决策"，代码里有注释。→ models.py / 界面"测算口径"折叠区。

**Q8 IRR 求不出来怎么办？（他们可能测试你）**
参考：现金流非常规时可能无解/多重解，代码返回 None，界面提示改用 NPV 判断——测试用例覆盖。

**Q9 敏感性分析的结果怎么用？**
参考：找出影响最大的变量（tornado 图最宽条）→ 经营管控重点 + 悲观情景压力测试。

**Q10 你如何保证报告里数字不是 AI 编的？**
参考：三层保障——①财务章节纯代码生成（不经模型）；②模型只写市场/风险两章且提示词禁止编数、只能引用"已知事实"；③单测"模型抽风时数字依然正确"（tests/test_workflow.py 最后一个用例）。

## C. 技术与架构

**Q11 整体架构是怎样的？**
参考：engine（纯计算）→ knowledge（RAG）→ workflow（报告流水线）→ reports（导出）→ Streamlit UI；数据流图见 docs/architecture.md。

**Q12 你的 RAG 是怎么实现的？**
参考：markitdown 解析文档（PDF/Word/Excel→文本）→ 按标题切块 → Embedding 向量化 → 自研 numpy 余弦 top-k 检索 → 带 [来源] 引用。→ knowledge/ 目录。

**Q13 为什么向量检索自己写，不用 chroma/FAISS？**
参考：①demo 规模矩阵乘法 <10ms 够用；②零部署纯 Python 可跑；③代码简单可讲原理；④接口已抽象（add/search），P2 换库只改一个类。→ store.py。

**Q14 大模型换厂商怎么办？**
参考：全部走 OpenAI 兼容协议，配置在 .env（BASE_URL/API_KEY/MODEL），换 DeepSeek/通义/智谱只改三行。→ llm/client.py。

**Q15 控制成本做了哪些事？**
参考：①财务章节不走模型；②只有市场/风险两章调用模型；③界面展示 token 消耗；④Embedding 用 BGE 免费档。

**Q16 一次完整报告大概花多少钱？**
参考：约 2~5 分钱量级（视模型价格），界面会显示 token 数。

**Q17 单元测试覆盖了什么？**
参考：财务公式 vs 手算例题（7 项）、知识库切块与检索、LLM 配置错误路径、报告流水线（含"模型抽风"安全用例）、Word 导出——共 25 项，全绿。→ tests/。

## D. 项目归属与合规（诚实底线）

**Q18 "这代码是 AI 写的，能算你的项目吗？"**
参考：能力=定义问题+设计口径+验收结果+讲清原理。我能现场讲每行关键逻辑、公式出处和测试设计——这比背代码更有价值。GitHub 有完整 commit 历史与文档可查。

**Q19 用了哪些开源项目？许可合规吗？**
参考：markitdown(MIT)、streamlit(Apache-2.0)、plotly(MIT)、python-docx(MIT)；RAGFlow/LangGraph/NextChat 只借鉴思路并文档注明。财务引擎、检索、报告流水线、全套文档为自研。→ README"借力清单"。

**Q20 数据安全？**
参考：用户文件只存本机 data/uploaded；仅调 API 时把文本发给所选厂商；.env 密钥不入库（.gitignore 忽略）；MVP 无登录，多人部署属 P1。

## 实战附录：AI 在真实冒烟中问过的问题（背下来 = 现场有料）

来源：docs/smoke-report.md（真实 DeepSeek 调用记录，非编造）。

**好项目（奶茶店基准）实测提问：**
1. "首年收入 65 万是否基于实地调研？是否考虑寒暑假/周末淡季？"
2. "6% 年增速长期维持是否过于乐观（市场饱和、竞争者进入）？"
3. "年固定成本 25.8 万是否含全部费用？是否考虑租金与人工上涨？"
4. "13 万杯年销量与 65 万收入（单价 5 元）是否匹配？是否考虑产能与实际销售波动？"
5. "10% 折现率是否反映项目风险？小本经营风险较高，是否应更高？"

**坏项目（悲观压力测试）实测提问（说明它能抓矛盾）：**
- "设计销量 13 万杯×5 元对应满产收入 65 万，首年 20 万收入利用率仅 30.8%，是否过于悲观？"
- "年固定成本 30 万已远超首年收入（占收入 150%），是否高估了租金/人工？"

**面试用法**：被问"AI 审核具体审什么？"时，直接抛上面任意一条真实提问 +
你的应对（"我会改参数重算，或给出客流依据"），比背概念可信得多。
