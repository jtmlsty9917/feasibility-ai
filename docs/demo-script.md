# FeasAI 演示脚本（10 分钟版）

> 用途：面试 / 作品集录屏 / 给导师合伙人演示。
> 原则：演示里只做"真实发生"的事——数字是引擎算的，报告点一下就生成。
> 环境：启动前确认 `.env` 已配好 Key；`streamlit run app.py`。

## 第 0~1 分钟｜一句话开场（背熟）

"这是我的个人项目 **FeasAI——项目可行性研究 AI 助手**。
一句话：把项目想法填进去，十几分钟得到一份**财务真算、有引用来源**的可研报告。
我学技术经济及管理，所以把课程里的 NPV、IRR、敏感性分析做成了产品，再用大模型自动成文——
关键设计是：**大模型只负责写文字，所有财务数字由我自己写的 Python 引擎计算，不允许 AI 编数。**"

## 第 1~3 分钟｜标签①财务测算（互动，证明"真算"）

1. 指着默认"学校旁奶茶店"示例 → "这是内置示例：建设投资 32 万 + 流动资金 4 万，首年收入 65 万。"
2. 展示指标卡：NPV ≈ 94.5 万元、IRR 46.8%、动态回收期 2.9 年、盈亏平衡 99,625 杯/年（77% 产能）。
3. **现场改动**：把"年固定经营成本"从 25.8 万改成 30 万 → 页面即时重算。
   - 台词："看到了吗？我改一个数，NPV 立刻变。这说明数字是算出来的，不是模型编的。"
4. 点开"敏感性分析"tornado 图 → "最上面是影响最大的参数，经营时重点盯住它。"

**可能被问**："IRR 怎么算的？" → 打开 `feasibility_ai/engine/indicators.py` 现场指：
"让 NPV=0 的折现率，代码里用二分法数值求解，几百次迭代收敛到 1e-9。"（讲得出=加分）

## 第 3~6 分钟｜标签②AI 可研报告（核心卖点）

1. 点"🤖 生成完整可研报告"，等 20~60 秒（期间说架构）：
   - "它内部是一条流水线：先让 AI 审我的假设、提问；财务章节由代码从引擎 JSON 直接生成；
     只有市场分析和风险分析两章交给大模型，而且我强制它只能用给定数字，不许编。"
2. 报告出来后：先指"🧐 AI 假设审核意见"→"看，AI 会质疑我的假设，这是人机协作，不是一键生成就完事。"
3. 滚动到"三、财务测算"→"这里每个数字都来自引擎"；到"四、风险"→"AI 的分析也是基于敏感性测算结果写的。"
4. 点"⬇️ 下载 Word 版报告"→ 打开给镜头看格式。

## 第 6~9 分钟｜标签③资料问答（RAG，若时间够）

1. 上传 `data/samples/行业资料示例.md`（或任意研报 PDF）→ 点"解析并入知识库"。
2. 提问："这份材料里，食品安全监管的重点是什么？" → 展示带 [来源] 的回答。
3. 台词："每个论断都能追溯到原文片段，报告里引用也是同一套知识库。"

## 第 9~10 分钟｜收尾（埋钩子）

"这个项目里我负责产品定义、业务口径和验收，开发用 AI 辅助完成——
我认为 AI 时代产品经理的核心是**能把业务问题翻译成技术方案并验证结果**。
代码、测试、PRD 都在我的 GitHub，欢迎随时看。"（→ 给面试官留追问空间）
