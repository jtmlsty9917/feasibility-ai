# 里程碑与验收清单（FeasAI）

> 节奏：作者每周投入 5~10 小时（验收 + 学习），代码由 AI Agent 编写。
> 倒排目标：2026 年内完成 M0~M2（有可演示闭环），2027 年 2~5 月完成 M3/M4（完整作品 + 简历），从容覆盖暑期实习与 2027 秋招。

> **进度快照（2026-09）**：M0 ✅ → M1 ✅ → M2 ✅（含**真实 API 冒烟通过**，见 smoke-report.md）→
> M3 大部分 ✅（Word 导出/演示脚本/面试 QA 20 题/简历素材/部署方案/离线预览）→
> 当前：作者试玩反馈、git 提交与 GitHub、录屏演示（M4 进行中）。

## 每个里程碑的通用交付物

1. 可运行的代码（作者本机可一键启动）；
2. 本里程碑的**验收清单**（作者逐项打勾）；
3. **"面试三句话"**：该阶段成果的一句话介绍、一句技术亮点、一句业务价值；
4. 作者的学习任务（读哪个文件、能回答什么问题）。

## M0 —— 环境与骨架（约 1 周）

**目标**：跑通"能启动的空项目"，作者电脑装好 Python 环境。
**产出**：项目骨架、requirements.txt、.env.example、PRD 定稿、示例场景选定。
**验收清单**：
- [ ] 本机 Python 3.11+ 可用；`streamlit run app.py` 能打开页面（显示占位内容）
- [ ] PRD v0.1 作者已逐条看过并确认/修改
- [ ] 大模型 API Key 已申请并填入 `.env`（M2 才真正用到，先备好）
- [ ] 选定示例演示项目（奶茶店/技术创业/设备更新，见对话提问）

**面试三句话（暂）**：这个项目解决"非财务背景的人不会做可研测算"的问题；我先搭了干净的模块骨架，把'算数'和'写报告'彻底分开；我的角色是产品定义与验收，开发由 AI 辅助完成，我负责把关正确性。

**学习任务**：通读 `docs/architecture.md` 数据流图，能对着图讲一遍"参数进去、报告出来"。

---

## M1 —— 财务引擎 MVP（1~2 周，先不接 LLM）

**目标**：**没有大模型也能跑** —— 填参数 → 出 NPV/IRR/回收期/盈亏平衡/敏感性图表 + 现金流表。这是全项目可信度的地基。
**验收清单**：
- [ ] 表单填写"奶茶店样例"→ 得到逐年现金流表与 5 类指标
- [ ] 指标与**手算例题**一致（Agent 会写单元测试，作者抽查 1 个数即可）
- [ ] 改一个参数（如房租 +20%）→ 图表即时更新
- [ ] 界面上每个指标旁有一句话"这是什么意思"（作者能看懂）

**面试三句话**：最核心的财务测算我做成纯函数、和 AI 完全隔离；比如 IRR 是让 NPV 等于 0 的折现率，用数值迭代求解；演示里我现场改房租，NPV 立刻变，说明数字是算出来的不是编的。

**学习任务**：精读 `engine/cashflow.py` 的 NPV 函数与注释；能用自己的话解释"NPV 大于 0 为什么可以做"。

---

## M2 —— 接入大模型：报告 + 问答（+1~2 周）

**目标**：闭环成立 —— 假设审核提问 → 引擎测算 → 自动生成 6 章可研报告 → 资料问答（方案 2 功能并入）。
**验收清单**：
- [ ] AI 会就录入提 3~5 个"假设疑点"，作者修改后重算
- [ ] 生成报告：财务章节数字与引擎一致（抽查）；资料性论断带 `[来源]` 引用
- [ ] 上传一份研报/政策 PDF → 可问答"里面说补贴比例是多少"
- [ ] 追问"房租涨 30% 会怎样？"→ 更新对应章节与图表
- [ ] 全程可见每步 LLM 花费提示

**面试三句话**：报告像流水线一样生产——先审假设、再算数、后行文，财务数字强制从引擎注入，LLM 只写文字不碰数字；资料问答走 RAG，能指出每个结论的来源；追问可以触发重算，形成'对话式可研'。

**学习任务**：能画出"问答/报告生成"的数据流程图（对着架构文档抄一遍即可）。

## M3 —— 打磨与导出（+2~3 周）

**目标**：作品级完成度 —— Word 导出、错误处理、README、架构图、演示脚本、中文注释补全、10 分钟 Demo 可复现。
**验收清单**：
- [ ] 报告一键导出 Word，格式可交给导师/合伙人看
- [ ] 断网/Key 失效/空输入等异常有友好提示
- [ ] README + 架构图 + 演示脚本（含台词）齐全
- [ ] 作者能不看文档跑完一遍 Demo（录屏备用）

**面试三句话**：我把它打磨成能给非技术用户直接用的工具，还写了 README 和演示脚本；任何一步出错都有明确提示；10 分钟我能完整演示'从想法到报告'。

**学习任务**：写一页"项目复盘"（动机、难点、取舍、结果），放简历作品集。

## M4 —— 部署与简历包装（2027 年 2~5 月内）

**目标**：上线演示 + 简历/作品集/面试 QA 全套。
**产出**：部署方案（本机演示录屏 / 云服务器二选一，届时再定）、简历项目条目文案、作品集链接、面试 QA 清单（技术面 / 非技术面两个版本，预计 30~50 题）。
**验收清单**：
- [ ] 面试官能访问演示（URL 或 5 分钟录屏）
- [ ] 简历项目条目 ≤ 6 行，突出"自研财务引擎 + 人机协作 + 完整业务文档"
- [ ] QA 清单作者至少过两遍

## 风险与应对

| 风险 | 应对 |
|---|---|
| 作者时间中断（实习/课程） | 每阶段都有"最小可演示产物"，断点不丢成果 |
| 国内模型 API 不稳定/限流 | llm 模块可一键切换厂商；engine 模块无 LLM 也能演示 |
| 财务口径被面试官挑战 | 代码注释注明假设口径 + 备好"简化与真实可研的差异"解释 |
| 简历被问"代码是不是你写的" | 如实说明 AI 辅助 + 展示作者能讲清每行关键逻辑与测试 |
